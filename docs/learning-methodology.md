# 学習方法

学習はレース日順のexpanding-window walk-forwardで行う。学習、検証、テスト期間は重複させず、予想時点以後のレースを特徴量にも校正にも使用しない。

更新対象はエージェントごとの特徴量重み、確率温度、最低EV、最低信頼度、条件別補正である。最低500標本、更新幅5%以下、正則化、直近データ比率上限35%を適用する。特徴量重みは勝者ラベルとレース内予測確率の誤差からエージェント別に勾配を計算し、空の更新値や全員共通の更新値は使用しない。

公開済みかつ結果確定済みで、予想時刻・オッズ観測時刻・締切時刻の順序が正しいスナップショットだけを学習へ入れる。研究用の事後再現、結果列を含む入力、締切後オッズは除外する。

選定指標はROIだけではなく、Brier Score、Log Loss、ECE、券種別の下方校正誤差、最大ドローダウン、日次収益のSharpe類似値を併用する。新モデルは旧版を消さず、ロールバック可能な版として保存する。

重み更新は検証期間とテスト期間の両方でLog Lossが悪化せず、本命1着率も悪化しない場合だけ有効化する。不合格候補は理由と指標を学習イベントへ記録し、本番へ混ぜない。
