# 広告・スポンサー運用方針

## 原則

- 広告は「広告」「PR」「スポンサー」のいずれかを画面内に明記する。
- 広告主はAIの印、指数、買い目、順位、結果集計へ関与できない。
- 的中や利益を保証する広告、投票代行、年齢制限回避につながる広告は掲載しない。
- リンク計測やCookieを追加する場合は、その利用目的を公開する。
- 架空の提携先、契約前のロゴ、仮のアフィリエイトIDは表示しない。

## 実装済み

- ロビー下部のスポンサー枠
- `/partners/`の掲載方針と相談導線
- Vercel Web Analytics / Speed Insights
- 予想ロジックと広告枠のDOM・データ分離

## 配信開始時の確認

1. 広告サービスの審査と契約を完了する。
2. 発行された正式なサイトID・広告枠IDだけを環境変数または設定へ登録する。
3. PR表記、遷移先、計測、表示速度、モバイル崩れを確認する。
4. 予想結果とランキングが広告の有無で変わらないことを回帰テストする。
