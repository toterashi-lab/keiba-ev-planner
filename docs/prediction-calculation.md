# 確率と期待値

市場確率は控除率を含む単純な逆数ではなく、全出走馬で正規化する。

`市場確率 = (1 / 単勝オッズ) / Σ(1 / 全馬の単勝オッズ)`

各エージェントは利用可能な特徴量だけを重み付きで合成し、レース内でsoftmax正規化する。欠損特徴量は0で補完せず、信頼度と品質ゲートへ反映する。

総合本命は5人の単純多数決では決めない。予想時点の単勝市場を精度下限とし、能力モデルが時系列外部検証で市場を上回った場合だけ、各エージェントの検証済み信頼度を使った対数プールを加える。検証不合格時の市場重みは100%、合格時も50%未満にしない。

`総合確率 ∝ 市場確率^市場重み × Π(各AI確率^AI信頼度重み)`

全頭を採点してから上位5頭へ印を付ける。印が付いた5頭だけを再採点する処理は禁止する。

`適正オッズ = 1 / 校正済み勝率`

`100円あたり期待払戻 = 校正済み勝率 × 現在オッズ × 100`

`100円あたり期待利益 = 期待払戻 - 100`

複勝、馬連、ワイド、3連複、3連単は順位確率モデルから組合せ確率を導く。券種別の時系列校正が未完了なら`参考推定`と表示し、購入適格にはしない。

過去アーカイブの`historical_closing_reference`は締切時刻を保証できない研究用再現であり、公開済み発走前予想の成績へ混ぜない。
