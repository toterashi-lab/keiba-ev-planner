# 直近運用ベースライン

今週の全レース予想を停止させないため、長期の期待値研究モデルとは別に、直近12か月の確定結果だけで能力確率を出すベースラインを用意する。

## 対象と分割

- 予測対象期間: 学習実行日時点の最新確定レースまでの直近12か月
- 履歴助走期間: 予測対象開始の18か月前から。各馬の近走・適性・騎手成績を作るためだけに使う
- 評価: 学習6か月、校正2か月、テスト2か月、7日embargoのexpanding-window walk-forwardを最低2回
- 予測時点より後の結果は特徴量に含めない

## 出力の扱い

`scripts/train-recent-forecast-baseline.mjs` は、ライブ出馬表の5エージェント予想で使える能力確率モデルを生成する。

この成果物は `benchmark_only` であり、単勝・複勝を含む過去の発走前オッズ検証、券種別校正、ROI信頼区間、最大ドローダウンのゲートを代替しない。したがって、買い目の収益性を保証する根拠には使用しない。

## 実行

```powershell
node --experimental-sqlite scripts/train-recent-forecast-baseline.mjs
```

生成物は私有データ領域の `models/ability-softmax-v1.json` に保存する。公開サイトにはモデル版と「検証中」の状態だけを表示し、研究用の指標は裏側の監査情報に保持する。
